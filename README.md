# Ideia do site:

# 1. Descrição do Sistema
O sistema consiste em uma plataforma web interativa desenvolvida para auxiliar jogadores durante a campanha de Look Outside. O objetivo principal é fornecer um guia completo da jornada, permitindo acompanhar o progresso, visualizar rotas possíveis, consultar informações sobre áreas, chefes, itens e objetivos.
O sistema busca melhorar a experiência de exploração do jogador, organizando informações do jogo em uma interface simples, visual e personalizada.

# 1. Objetivo Geral
Desenvolver um guia interativo capaz de acompanhar a evolução do jogador durante sua jornada, oferecendo informações estratégicas, controle de progresso e auxílio na exploração do mundo do jogo.

# 1. Objetivos Específicos
- Permitir que o jogador acompanhe seu progresso na campanha.
- Apresentar mapa com filtros 
- Exibir informações sobre áreas, inimigos, chefes e itens.
- Auxiliar o jogador na escolha dos próximos objetivos 
- Exibir um guia da história do jogo a medida que o jogador for explorando 
- Definir dificuldade e estratégias para chefões e desafios durante a progressão 
- Mostra onde pega cada item e mostra a descrição daquele item e para que ele serve 
- Informações sobre a platina dentro do jogo

- Diário de aventura 
O diária de aventura seria tipo um feedback de uma missão ou boss que seria mostrado como um chat global.
